# 数据模型设计: YouTube智能字幕增强器

**日期**: 2026-01-20  
**项目**: YouTube智能字幕增强器  
**分支**: `001-youtube-subtitle-enhancer`

## 概述

本文档定义YouTube智能字幕增强器的核心数据模型、存储结构和实体关系。所有数据主要存储在Chrome扩展的`chrome.storage.local` API中，部分临时数据使用内存缓存。

---

## 1. 核心实体

### 1.1 UserProfile (用户配置)

**用途**: 存储用户的个人设置和词汇表

**存储位置**: `chrome.storage.local`

**Schema**:
```typescript
interface UserProfile {
  // 英语水平
  englishLevel: 'beginner' | 'intermediate' | 'advanced';
  
  // LLM API配置
  llmProvider: 'openai' | 'claude';
  llmApiKey: string; // 用户提供的API密钥
  llmModel?: string; // 可选，指定模型(默认: gpt-4o-mini / claude-3-5-haiku)
  
  // 词汇表
  masteredWords: WordEntry[]; // 已掌握词汇
  focusWords: WordEntry[]; // 重点关注词汇
  
  // UI偏好
  subtitleFontSize: number; // 字幕字体大小(px, 默认16)
  subtitleFontColor: string; // 字幕颜色(默认'#ffffff')
  subtitleBackgroundColor: string; // 背景颜色(默认'rgba(0,0,0,0.8)')
  translationColor: string; // 翻译文本颜色(默认'#ffeb3b')
  
  // 扩展状态
  isEnabled: boolean; // 扩展总开关(默认true)
  showOnboardingGuide: boolean; // 是否显示新手引导(默认true)
  
  // 统计数据(可选)
  totalVideosWatched?: number;
  totalWordsLearned?: number;
  createdAt: number; // 首次安装时间戳
  lastUsedAt: number; // 最后使用时间戳
}
```

**WordEntry子实体**:
```typescript
interface WordEntry {
  word: string; // 单词(小写)
  lemma?: string; // 词根形式(用于词形识别)
  addedTime: number; // 添加时间戳(毫秒)
  source?: 'manual' | 'interactive'; // 来源(手动添加/交互标记)
}
```

**Storage Key**: `user_profile`

**默认值**:
```typescript
const defaultUserProfile: UserProfile = {
  englishLevel: 'intermediate',
  llmProvider: 'openai',
  llmApiKey: '',
  masteredWords: [],
  focusWords: [],
  subtitleFontSize: 16,
  subtitleFontColor: '#ffffff',
  subtitleBackgroundColor: 'rgba(0,0,0,0.8)',
  translationColor: '#ffeb3b',
  isEnabled: true,
  showOnboardingGuide: true,
  createdAt: Date.now(),
  lastUsedAt: Date.now(),
};
```

**访问方法**:
```typescript
// 读取用户配置
async function getUserProfile(): Promise<UserProfile> {
  const result = await chrome.storage.local.get('user_profile');
  return result.user_profile || defaultUserProfile;
}

// 更新用户配置
async function updateUserProfile(updates: Partial<UserProfile>): Promise<void> {
  const current = await getUserProfile();
  const updated = { ...current, ...updates, lastUsedAt: Date.now() };
  await chrome.storage.local.set({ user_profile: updated });
}
```

**数据大小估算**:
- 基础配置: ~500 bytes
- 每个单词: ~50 bytes (word + lemma + metadata)
- 10000词上限: ~500 KB
- **总计: <1 MB (chrome.storage.local限制为~5-10 MB)**

### 1.2 SubtitleSegment (字幕片段)

**用途**: 表示视频字幕中的一个时间段片段

**存储位置**: 临时内存(不持久化) / 缓存到chrome.storage.local(按视频ID)

**Schema**:
```typescript
interface SubtitleSegment {
  // 时间轴
  startTime: number; // 开始时间(秒)
  endTime: number; // 结束时间(秒)
  
  // 文本内容
  originalText: string; // 原始英文文本
  enhancedHTML: string; // 增强后的HTML(包含翻译标注)
  
  // 单词分析
  words: WordAnalysis[]; // 单词列表及翻译状态
}
```

**WordAnalysis子实体**:
```typescript
interface WordAnalysis {
  word: string; // 单词原形
  lemma: string; // 词根
  isUnknown: boolean; // 是否为生词(需要翻译)
  translation?: string; // LLM生成的中文解释
  position: { start: number; end: number }; // 在originalText中的位置
}
```

### 1.3 VideoSession (视频会话)

**用途**: 跟踪用户当前观看的视频及其字幕状态

**存储位置**: `chrome.storage.local` (缓存) + 内存(运行时)

**Schema**:
```typescript
interface VideoSession {
  // 视频标识
  videoId: string; // YouTube视频ID
  videoTitle?: string; // 视频标题(可选)
  
  // 字幕数据
  subtitleLanguage: string; // 字幕语言代码(如'en')
  subtitleTrackUrl: string; // 字幕API URL
  isAutoGenerated: boolean; // 是否为自动生成字幕
  segments: SubtitleSegment[]; // 所有字幕片段
  
  // 处理状态
  isProcessing: boolean; // 是否正在处理字幕
  processingProgress: number; // 处理进度(0-100)
  lastProcessedTime: number; // 最后处理时间戳
  
  // 缓存元数据
  cacheExpiry: number; // 缓存过期时间戳(7天)
}
```

**Storage Key**: `video_cache_${videoId}`

**缓存策略**:
```typescript
// 缓存有效期: 7天
const CACHE_EXPIRY_MS = 7 * 24 * 60 * 60 * 1000;

async function cacheVideoSession(session: VideoSession): Promise<void> {
  const cacheKey = `video_cache_${session.videoId}`;
  const cacheData = {
    ...session,
    cacheExpiry: Date.now() + CACHE_EXPIRY_MS,
  };
  await chrome.storage.local.set({ [cacheKey]: cacheData });
}

async function getCachedVideoSession(videoId: string): Promise<VideoSession | null> {
  const cacheKey = `video_cache_${videoId}`;
  const result = await chrome.storage.local.get(cacheKey);
  const cached = result[cacheKey];
  
  if (!cached) return null;
  
  // 检查过期
  if (Date.now() > cached.cacheExpiry) {
    await chrome.storage.local.remove(cacheKey);
    return null;
  }
  
  return cached;
}
```

### 1.4 TranslationCache (翻译缓存)

**用途**: 缓存LLM API的翻译结果，减少重复调用

**存储位置**: `chrome.storage.local`

**Schema**:
```typescript
interface TranslationCacheEntry {
  word: string; // 单词
  context: string; // 上下文(字幕原文，限制前50字符)
  contextHash: string; // 上下文哈希(用于快速查找)
  translation: string; // LLM生成的中文解释
  timestamp: number; // 缓存时间戳
  expiryTime: number; // 过期时间戳(7天)
  llmProvider: 'openai' | 'claude'; // 使用的LLM提供商
  llmModel: string; // 使用的模型
}
```

**Storage Key**: `translation_cache_${contextHash}`

**缓存管理**:
```typescript
// 生成上下文哈希
function generateContextHash(word: string, context: string): string {
  const snippet = context.slice(0, 50);
  return `${word}_${simpleHash(snippet)}`;
}

function simpleHash(str: string): string {
  let hash = 0;
  for (let i = 0; i < str.length; i++) {
    const char = str.charCodeAt(i);
    hash = (hash << 5) - hash + char;
    hash = hash & hash; // Convert to 32bit integer
  }
  return hash.toString(36);
}

// 写入缓存
async function cacheTranslation(
  word: string,
  context: string,
  translation: string,
  provider: string,
  model: string
): Promise<void> {
  const contextHash = generateContextHash(word, context);
  const cacheKey = `translation_cache_${contextHash}`;
  
  const entry: TranslationCacheEntry = {
    word,
    context: context.slice(0, 50),
    contextHash,
    translation,
    timestamp: Date.now(),
    expiryTime: Date.now() + 7 * 24 * 60 * 60 * 1000, // 7天
    llmProvider: provider as any,
    llmModel: model,
  };
  
  await chrome.storage.local.set({ [cacheKey]: entry });
}

// 读取缓存
async function getTranslationCache(word: string, context: string): Promise<string | null> {
  const contextHash = generateContextHash(word, context);
  const cacheKey = `translation_cache_${contextHash}`;
  
  const result = await chrome.storage.local.get(cacheKey);
  const entry = result[cacheKey] as TranslationCacheEntry;
  
  if (!entry) return null;
  
  // 检查过期
  if (Date.now() > entry.expiryTime) {
    await chrome.storage.local.remove(cacheKey);
    return null;
  }
  
  return entry.translation;
}
```

**缓存清理**:
```typescript
// 定期清理过期缓存(每天执行一次)
async function cleanupExpiredCaches(): Promise<void> {
  const allKeys = await chrome.storage.local.get(null);
  const keysToRemove: string[] = [];
  
  for (const [key, value] of Object.entries(allKeys)) {
    if (key.startsWith('translation_cache_')) {
      const entry = value as TranslationCacheEntry;
      if (Date.now() > entry.expiryTime) {
        keysToRemove.push(key);
      }
    }
    
    if (key.startsWith('video_cache_')) {
      const session = value as VideoSession;
      if (Date.now() > session.cacheExpiry) {
        keysToRemove.push(key);
      }
    }
  }
  
  if (keysToRemove.length > 0) {
    await chrome.storage.local.remove(keysToRemove);
    console.log(`Cleaned up ${keysToRemove.length} expired cache entries`);
  }
}

// 在Service Worker启动时运行清理
chrome.runtime.onStartup.addListener(() => {
  cleanupExpiredCaches();
});
```

## 3. 存储配额管理

### 3.1 存储空间估算

```typescript
// 存储空间使用估算
interface StorageEstimate {
  userProfile: number; // ~500 bytes + (词汇数 * 50 bytes)
  videoCaches: number; // 每个视频 ~100-500 KB (取决于字幕长度)
  translationCaches: number; // 每个翻译 ~200 bytes
  total: number;
}

async function getStorageUsage(): Promise<StorageEstimate> {
  const allData = await chrome.storage.local.get(null);
  
  let estimate: StorageEstimate = {
    userProfile: 0,
    videoCaches: 0,
    translationCaches: 0,
    total: 0,
  };
  
  for (const [key, value] of Object.entries(allData)) {
    const size = JSON.stringify(value).length;
    
    if (key === 'user_profile') {
      estimate.userProfile = size;
    } else if (key.startsWith('video_cache_')) {
      estimate.videoCaches += size;
    } else if (key.startsWith('translation_cache_')) {
      estimate.translationCaches += size;
    }
  }
  
  estimate.total = estimate.userProfile + estimate.videoCaches + estimate.translationCaches;
  
  return estimate;
}
```

### 3.2 配额监控与告警

```typescript
// chrome.storage.local 配额: ~5-10 MB (取决于Chrome版本)
const STORAGE_QUOTA_BYTES = 10 * 1024 * 1024; // 10 MB
const STORAGE_WARNING_THRESHOLD = 0.8; // 80%

async function checkStorageQuota(): Promise<{ usage: number; quota: number; isNearLimit: boolean }> {
  const usage = await getStorageUsage();
  const isNearLimit = usage.total > STORAGE_QUOTA_BYTES * STORAGE_WARNING_THRESHOLD;
  
  if (isNearLimit) {
    console.warn(`Storage usage (${(usage.total / 1024 / 1024).toFixed(2)} MB) is approaching limit`);
    // 触发清理
    await cleanupOldestCaches();
  }
  
  return {
    usage: usage.total,
    quota: STORAGE_QUOTA_BYTES,
    isNearLimit,
  };
}

async function cleanupOldestCaches(): Promise<void> {
  const allData = await chrome.storage.local.get(null);
  const caches: Array<{ key: string; timestamp: number }> = [];
  
  // 收集所有缓存及其时间戳
  for (const [key, value] of Object.entries(allData)) {
    if (key.startsWith('video_cache_')) {
      caches.push({ key, timestamp: (value as VideoSession).lastProcessedTime });
    } else if (key.startsWith('translation_cache_')) {
      caches.push({ key, timestamp: (value as TranslationCacheEntry).timestamp });
    }
  }
  
  // 按时间戳排序，删除最老的30%
  caches.sort((a, b) => a.timestamp - b.timestamp);
  const toDelete = caches.slice(0, Math.floor(caches.length * 0.3));
  
  await chrome.storage.local.remove(toDelete.map(c => c.key));
  console.log(`Cleaned up ${toDelete.length} oldest cache entries`);
}
```

### 4.2 迁移策略

```typescript
/**
 * 数据迁移管理器
 * 处理扩展更新时的数据模型变更
 */
class DataMigrationManager {
  async checkAndMigrate(): Promise<void> {
    const dataVersion = await this.getDataVersion();
    
    if (!dataVersion || dataVersion.version !== CURRENT_DATA_VERSION) {
      console.log(`Migrating data from ${dataVersion?.version || 'unknown'} to ${CURRENT_DATA_VERSION}`);
      await this.runMigrations(dataVersion?.version || '0.0.0');
      await this.setDataVersion(CURRENT_DATA_VERSION);
    }
  }
  
  private async runMigrations(fromVersion: string): Promise<void> {
    // 示例: 从v1.0.0迁移到v1.1.0
    if (fromVersion === '1.0.0') {
      await this.migrateFrom1_0_0To1_1_0();
    }
  }
  
  private async migrateFrom1_0_0To1_1_0(): Promise<void> {
    // 示例迁移: 添加新字段到UserProfile
    const profile = await getUserProfile();
    if (!profile.totalVideosWatched) {
      profile.totalVideosWatched = 0;
      profile.totalWordsLearned = 0;
      await updateUserProfile(profile);
    }
  }
  
  private async getDataVersion(): Promise<DataVersion | null> {
    const result = await chrome.storage.local.get('data_version');
    return result.data_version || null;
  }
  
  private async setDataVersion(version: string): Promise<void> {
    await chrome.storage.local.set({
      data_version: {
        version,
        lastMigration: Date.now(),
      },
    });
  }
}

// 在扩展安装/更新时运行迁移
chrome.runtime.onInstalled.addListener(async (details) => {
  if (details.reason === 'install' || details.reason === 'update') {
    const migrationManager = new DataMigrationManager();
    await migrationManager.checkAndMigrate();
  }
});
```

## 7. 数据安全与隐私

### 7.1 敏感数据保护

```typescript
// LLM API密钥存储在chrome.storage.local(Chrome自动加密)
// 不需要额外加密，Chrome扩展存储已隔离且加密

// ❌ 错误做法: 将API密钥硬编码或发送到服务器
const apiKey = "sk-abc123"; // 禁止硬编码

// ✅ 正确做法: 用户输入，存储在本地
async function saveApiKey(key: string) {
  await chrome.storage.local.set({ llm_api_key: key });
}
```

### 7.2 数据隐私承诺

- ✅ **本地存储**: 所有用户数据(配置、词汇表、缓存)仅存储在用户本地Chrome扩展存储中
- ✅ **无服务器传输**: 扩展不向任何第三方服务器发送用户数据(除了用户主动配置的LLM API调用)
- ✅ **LLM API透明**: LLM API调用由用户自行提供API密钥和控制，扩展开发者无法访问
- ✅ **数据可导出**: 用户可随时导出词汇表为CSV，完全掌控自己的数据
- ✅ **数据可删除**: 卸载扩展后，chrome.storage.local数据自动清除

## 8. 性能优化

### 8.1 内存管理

```typescript
// Service Worker生命周期管理
// Manifest V3的Service Worker会自动休眠，需要优化内存使用

// ❌ 错误: 在Service Worker中维护大量常驻内存数据
let allVideoCaches = {}; // 会导致内存占用过高

// ✅ 正确: 按需从storage读取，缓存到临时变量
let currentVideoSession: VideoSession | null = null;

chrome.runtime.onSuspend.addListener(() => {
  // Service Worker即将休眠，清理内存
  currentVideoSession = null;
  console.log('Service worker suspended, memory cleared');
});
```

### 8.2 批量读写优化

```typescript
// ❌ 低效: 多次单独读写
for (const word of words) {
  await chrome.storage.local.set({ [word]: translation });
}

// ✅ 高效: 批量读写
const updates: Record<string, any> = {};
for (const word of words) {
  updates[word] = translation;
}
await chrome.storage.local.set(updates);
```
