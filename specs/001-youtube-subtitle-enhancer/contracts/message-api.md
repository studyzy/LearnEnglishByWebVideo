# 消息传递API合同

**版本**: 1.0.0  
**日期**: 2026-01-20

## 概述

本文档定义Chrome扩展内部组件之间的消息传递协议，包括Content Script ↔ Service Worker的双向通信。

---

## 1. 消息协议基础

### 1.1 消息结构

所有消息遵循统一格式:

```typescript
interface Message<T = any> {
  type: MessageType; // 消息类型
  payload?: T; // 消息载荷(可选)
  requestId?: string; // 请求ID(用于异步响应匹配)
}

interface MessageResponse<T = any> {
  success: boolean; // 是否成功
  data?: T; // 响应数据
  error?: string; // 错误信息
  requestId?: string; // 对应的请求ID
}
```

### 1.2 消息类型枚举

```typescript
enum MessageType {
  // 字幕相关
  GET_SUBTITLE = 'GET_SUBTITLE',
  SUBTITLE_READY = 'SUBTITLE_READY',
  PROCESS_SUBTITLE = 'PROCESS_SUBTITLE',
  
  // 翻译相关
  TRANSLATE_WORDS = 'TRANSLATE_WORDS',
  TRANSLATION_RESULT = 'TRANSLATION_RESULT',
  
  // 词汇管理
  ADD_MASTERED_WORD = 'ADD_MASTERED_WORD',
  REMOVE_WORD = 'REMOVE_WORD',
  CHECK_WORD_STATUS = 'CHECK_WORD_STATUS',
  
  // 配置相关
  GET_USER_PROFILE = 'GET_USER_PROFILE',
  UPDATE_USER_PROFILE = 'UPDATE_USER_PROFILE',
  
  // 状态同步
  EXTENSION_STATUS = 'EXTENSION_STATUS',
  VIDEO_CHANGED = 'VIDEO_CHANGED',
}
```

## 2. Content Script → Service Worker

### 2.1 获取字幕 (GET_SUBTITLE)

**场景**: Content script检测到YouTube视频加载，请求Service Worker获取并处理字幕

**请求**:
```typescript
interface GetSubtitleRequest {
  type: MessageType.GET_SUBTITLE;
  payload: {
    videoId: string;
    captionTrackUrl: string;
    isAutoGenerated: boolean;
  };
}
```

**响应**:
```typescript
interface GetSubtitleResponse {
  success: boolean;
  data?: {
    segments: SubtitleSegment[];
    videoId: string;
    processingTime: number; // 处理耗时(ms)
  };
  error?: string; // 如"No English captions available"
}
```

**示例**:
```typescript
// Content Script
const response = await chrome.runtime.sendMessage({
  type: MessageType.GET_SUBTITLE,
  payload: {
    videoId: 'dQw4w9WgXcQ',
    captionTrackUrl: 'https://www.youtube.com/api/timedtext?...',
    isAutoGenerated: false,
  },
});

if (response.success) {
  const segments = response.data.segments;
  renderSubtitles(segments);
}
```

### 2.2 翻译单词列表 (TRANSLATE_WORDS)

**场景**: Content script请求Service Worker调用LLM API翻译一批生词

**请求**:
```typescript
interface TranslateWordsRequest {
  type: MessageType.TRANSLATE_WORDS;
  payload: {
    words: Array<{
      word: string;
      context: string; // 完整句子
    }>;
  };
}
```

**响应**:
```typescript
interface TranslateWordsResponse {
  success: boolean;
  data?: {
    translations: Map<string, string>; // word -> 中文解释
    cacheHits: number; // 缓存命中数
    apiCalls: number; // 实际API调用数
  };
  error?: string;
}
```

**示例**:
```typescript
// Content Script
const response = await chrome.runtime.sendMessage({
  type: MessageType.TRANSLATE_WORDS,
  payload: {
    words: [
      { word: 'run', context: 'The program will run automatically.' },
      { word: 'automatically', context: 'The program will run automatically.' },
    ],
  },
});

if (response.success) {
  const translations = response.data.translations;
  console.log(translations.get('run')); // "运行"
}
```

### 2.3 添加熟词 (ADD_MASTERED_WORD)

**场景**: 用户通过交互式标记(点击×)将生词标记为熟词

**请求**:
```typescript
interface AddMasteredWordRequest {
  type: MessageType.ADD_MASTERED_WORD;
  payload: {
    word: string;
    source: 'interactive' | 'manual';
  };
}
```

**响应**:
```typescript
interface AddMasteredWordResponse {
  success: boolean;
  data?: {
    word: string;
    lemma: string; // 词根形式
    addedTime: number;
  };
  error?: string;
}
```

**示例**:
```typescript
// Content Script: 用户点击×标记
document.querySelector('.word-mark-btn').addEventListener('click', async () => {
  const word = event.target.dataset.word;
  
  const response = await chrome.runtime.sendMessage({
    type: MessageType.ADD_MASTERED_WORD,
    payload: {
      word: word,
      source: 'interactive',
    },
  });
  
  if (response.success) {
    // 移除当前字幕中的翻译标注
    removeTranslation(word);
  }
});
```

### 2.4 检查单词状态 (CHECK_WORD_STATUS)

**场景**: Content script需要快速判断一批单词是否为生词

**请求**:
```typescript
interface CheckWordStatusRequest {

```

**响应**:
```typescript
interface CheckWordStatusResponse {
  success: boolean;
  data?: {
    unknownWords: string[]; // 生词列表
    masteredWords: string[]; // 熟词列表
    focusWords: string[]; // 重点关注词列表

}
```

**示例**:
```typescript

const response = await chrome.runtime.sendMessage({
  type: MessageType.CHECK_WORD_STATUS,
  payload: {
    words: ['hello', 'world', 'sophisticated', 'algorithm'],
  },
});

if (response.success) {
  console.log('Unknown words:', response.data.unknownWords);
  // ["sophisticated", "algorithm"]
}
```

## 3. Service Worker → Content Script

### 3.1 扩展状态变更 (EXTENSION_STATUS)

**场景**: 用户在popup中开关扩展，Service Worker广播状态变更

**消息**:
```typescript
interface ExtensionStatusMessage {
  type: MessageType.EXTENSION_STATUS;
  payload: {
    isEnabled: boolean;
  };
}
```

**Content Script处理**:
```typescript
chrome.runtime.onMessage.addListener((message, sender, sendResponse) => {
  if (message.type === MessageType.EXTENSION_STATUS) {
    if (message.payload.isEnabled) {
      enableSubtitleEnhancement();
    } else {
      disableSubtitleEnhancement();
    }
  }
});
```

## 4. 错误处理

### 4.1 标准错误码

```typescript
enum ErrorCode {
  INVALID_API_KEY = 'INVALID_API_KEY',
  RATE_LIMIT_EXCEEDED = 'RATE_LIMIT_EXCEEDED',
  NETWORK_ERROR = 'NETWORK_ERROR',
  NO_CAPTIONS_AVAILABLE = 'NO_CAPTIONS_AVAILABLE',
  STORAGE_QUOTA_EXCEEDED = 'STORAGE_QUOTA_EXCEEDED',
  UNKNOWN_ERROR = 'UNKNOWN_ERROR',
}

interface ErrorResponse {
  success: false;
  error: string; // 用户友好的错误消息
  errorCode: ErrorCode; // 错误码
  details?: any; // 详细错误信息(调试用)
}
```

### 4.2 错误处理示例

```typescript
// Service Worker: 发送错误响应
if (!apiKey) {
  return {
    success: false,
    error: 'Please configure your LLM API key in settings',
    errorCode: ErrorCode.INVALID_API_KEY,
  };
}

// Content Script: 处理错误
const response = await chrome.runtime.sendMessage({ ... });
if (!response.success) {
  switch (response.errorCode) {
    case ErrorCode.INVALID_API_KEY:
      showNotification('Please set up your API key', 'error');
      break;
    case ErrorCode.RATE_LIMIT_EXCEEDED:
      showNotification('API rate limit reached, please wait', 'warning');
      break;
    default:
      showNotification(response.error, 'error');
  }
}
```

## 5. 性能优化

### 5.1 批量消息

❌ **低效: 多次单独发送消息**
```typescript
for (const word of words) {
  await chrome.runtime.sendMessage({
    type: MessageType.TRANSLATE_WORDS,
    payload: { words: [{ word, context }] },
  });
}
```

✅ **高效: 批量发送**
```typescript
await chrome.runtime.sendMessage({
  type: MessageType.TRANSLATE_WORDS,
  payload: {
    words: words.map(word => ({ word, context })),
  },
});
```

### 5.2 长时间操作

对于耗时操作(如处理30分钟视频字幕)，使用长连接(Port):

```typescript
// Content Script: 建立长连接
const port = chrome.runtime.connect({ name: 'subtitle-processing' });

port.onMessage.addListener((message) => {
  if (message.type === 'PROGRESS_UPDATE') {
    updateProgressBar(message.payload.progress);
  } else if (message.type === 'PROCESSING_COMPLETE') {
    handleSubtitles(message.payload.segments);
  }
});

port.postMessage({
  type: MessageType.PROCESS_SUBTITLE,
  payload: { videoId: 'abc123', captionUrl: '...' },
});

// Service Worker: 发送进度更新
chrome.runtime.onConnect.addListener((port) => {
  if (port.name === 'subtitle-processing') {
    port.onMessage.addListener(async (message) => {
      // 处理字幕，定期发送进度
      for (let i = 0; i < segments.length; i++) {
        await processSegment(segments[i]);
        port.postMessage({
          type: 'PROGRESS_UPDATE',
          payload: { progress: (i / segments.length) * 100 },
        });
      }
      
      port.postMessage({
        type: 'PROCESSING_COMPLETE',
        payload: { segments },
      });
    });
  }
});
```

## 6. 消息安全

### 6.1 验证发送者

```typescript
// Service Worker: 验证消息来自扩展内部
chrome.runtime.onMessage.addListener((message, sender, sendResponse) => {
  // 检查sender
  if (!sender.tab || sender.id !== chrome.runtime.id) {
    console.warn('Rejected message from unknown sender');
    sendResponse({ success: false, error: 'Invalid sender' });
    return;
  }
  
  // 处理消息...
});
```

### 6.2 输入验证

```typescript
// Service Worker: 验证payload
chrome.runtime.onMessage.addListener((message, sender, sendResponse) => {
  if (message.type === MessageType.ADD_MASTERED_WORD) {
    const { word } = message.payload;
    
    // 验证输入
    if (!word || typeof word !== 'string' || word.length === 0) {
      sendResponse({
        success: false,
        error: 'Invalid word parameter',
      });
      return;
    }
    
    // 处理...
  }
});
```

## 7. 消息API使用清单

| 消息类型 | 方向 | 用途 | 响应时间 |
|---------|------|------|----------|
| GET_SUBTITLE | CS→SW | 获取并处理视频字幕 | <3s |
| TRANSLATE_WORDS | CS→SW | 批量翻译生词 | <2s |
| ADD_MASTERED_WORD | CS→SW | 添加熟词 | <100ms |
| CHECK_WORD_STATUS | CS→SW | 批量检查单词状态 | <50ms |
| GET_USER_PROFILE | CS→SW | 获取用户配置 | <50ms |
| VIDEO_CHANGED | CS→SW | 视频切换通知 | <50ms |
| EXTENSION_STATUS | SW→CS | 扩展状态变更广播 | N/A |
| UPDATE_USER_PROFILE | SW→CS | 配置更新通知 | N/A |

**说明**: CS = Content Script, SW = Service Worker
